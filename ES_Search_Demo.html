What is Elasticsearch?

  • A distributed search and analytics engine
  • Stores data as JSON documents inside indexes
  • Builds an inverted index: word → documents
  • Everything is available over a REST API
  • Fast, near real-time, scales across nodes

How an inverted index works
  1. Split each message into words (tokens)
  2. For each word, store the list of messages that contain it
  3. A search looks the word up directly — no scanning every message

When the message is saved
  • Field text_sayt has type search_as_you_type
  • The text is analyzed into edge n-grams: p, pa, pas, pass … password
  • Word pairs (2- and 3-word shingles) are stored too
When you type
  • Your input goes through the same analyzer
  • bool_prefix query: earlier words match fully, the last word as a prefix
  • Runs on every keystroke (150 ms pause)
“pas” finds “password” — no full word needed
